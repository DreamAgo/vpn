# 网段组

后台「网段组」使用名称和多个 IPv4 CIDR 管理路由目录，例如「贵州内网」。输入框支持换行、空格、制表符、中英文逗号分隔，保存时统一校验、归一化网络地址并去重；空组、非法项和默认路由 /0 不允许保存。

用户组权限、节点路由和服务端 LAN 的选择器支持一次添加整个网段组，再逐项调整 CIDR。保存的是当时选中的路由值；修改或删除目录中的组不会自动改变已保存路由。路由使用数表示包含任一组内 CIDR 的配置数量，同一配置只计一次，并不表示按组 ID 绑定。

API 路径保留 `/api/v1/admin/subnets`。创建/更新推荐提交 `{"name":"贵州内网","cidrs":["135.10.0.0/16","10.196.184.0/24"]}`。省略更新字段表示不修改；空数组会被拒绝。旧 `cidr` 文本输入仍接受，但不能与 `cidrs` 同时赋值。响应新增 `cidrs` 数组，旧 `cidr` 字段为逗号分隔文本。

迁移保留原记录 ID、名称和时间戳，旧单网段记录成为只有一个 CIDR 的组。现有 `subnets.cidr` 列保存规范化 CSV，备份恢复无需转换；取消 CIDR 唯一限制，不同名称的组可包含相同 CIDR，组名仍唯一。创建多网段组后如需回退旧版本，应恢复升级前数据库备份。
