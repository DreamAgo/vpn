# 易链手机端交互 Demo

这是独立的设计原型，尚未应用到 Android APK。全部账号、连接、流量、下载及安装均为模拟；无外部依赖、无后端请求、不持久化表单输入。

## 页面与层级

- 连接：首页以连接状态和唯一主要操作为核心，工作网络、流量、时长可见；IP、网段、DNS 在详情弹层中展示。
- 活动：最近连接、取消、重连及失败记录；诊断复制作为二级操作。
- 我的：企业账号、服务地址、修改密码、应用更新及系统 VPN 设置。
- 登录：飞书主入口，密码登录备选；服务地址始终可见。

## 交互约定

- 连接中允许取消；成功依赖状态完成，不能按下按钮就显示已连接。
- 断开、切换服务、改密、退出及安装更新时按需先确认断开，保留用户控制。
- 错误卡先说明原因和恢复操作，再附错误码。6001 终端配额只是演示场景，不是对用户真实故障的诊断。
- 更新先展示版本说明、大小，再确认下载、校验、断开与系统安装；所有步骤均明确标注模拟。
- 手机弹层贴底、主导航固定；尊重减少动态效果设置；按钮可键盘访问、弹层支持 Escape。

## 演示与运行

使用页面的“体验场景”切换日常连接、首次登录、6001、重连及发现新版本。手机端入口在顶部“切换场景”。

```sh
python3 -m http.server 8877 --directory _bmad-output/planning-artifacts/android-ux-demo
```

本轮局域网部署在 `/private/tmp/yilian-android-download/demo/`，保留同目录原 APK 下载。
